# MVP 범위 지침

## 1차 MVP 포함 기능

### 출발 전: 오늘탈까

현재 위치 기준으로 자전거 타기 좋은지 판단한다.

표시 정보:

- 앱 이름: 오늘탈까
- 현재 위치
- 라이딩 적합도 점수
- 한 줄 판단 메시지
- 현재 기온
- 체감온도
- 습도
- 강수확률
- 강수 형태
- 하늘 상태/구름
- 풍속
- 풍향
- 미세먼지 PM10
- 초미세먼지 PM2.5
- 일몰 시간
- 라이딩 시작 버튼

라이딩 점수는 우선 단순 규칙 기반으로 만든다.

예시 감점 규칙:

- 강수확률 50% 이상: 큰 감점
- PM2.5 나쁨: 큰 감점
- 풍속 7m/s 이상: 감점
- 기온 30도 이상: 감점
- 습도 80% 이상 + 고온: 감점
- 일몰 임박: 주의 표시

점수 구간:

- 90점 이상: 매우 좋음
- 75~89점: 좋음
- 60~74점: 가능하지만 주의
- 40~59점: 짧은 라이딩만 추천
- 40점 미만: 비추천

### 라이딩 중: 기록

사용자가 라이딩 시작 버튼을 누르면 라이딩 세션이 생성된다.

필수 기능:

- 라이딩 시작
- 일시정지
- 재개
- 종료
- GPS 위치 기록
- 지도 위 현재 위치 표시
- 지도 위 이동 경로 표시
- 경과 시간 표시
- 총 거리 표시
- 현재 속도 표시
- 평균 속도 표시

라이딩 중 화면은 자전거를 타면서 보기 때문에 단순해야 한다.

- 숫자는 크고 명확하게 표시한다.
- 버튼은 큼직하게 만든다.
- 정보는 최소화한다.
- 지도와 핵심 수치 중심으로 구성한다.
- 라이딩 중 조작을 최소화한다.

### 종료 후: 오늘탔다

라이딩을 종료하면 요약 화면을 보여준다.

표시 정보:

- 총 거리
- 총 시간
- 이동 시간
- 평균 속도
- 최고 속도
- 경로 미니맵
- 시작 시점 날씨
- 종료 시점 날씨
- 미세먼지/초미세먼지 요약
- 사용자 메모
- 공유 카드 만들기 버튼

### 공유 카드

1차 MVP에서는 공유용 카드 1장만 만든다.

카드 포함 정보:

- 날짜
- 앱 이름: 오늘탈까
- 거리
- 시간
- 평균 속도
- 경로 미니맵
- 날씨 요약
- 미세먼지 요약
- 한 줄 메모

공유 방식:

- 앱에서 이미지를 생성한다.
- iOS 공유 기능으로 사용자가 직접 공유한다.
- 인스타그램, 블로그 등에 자동 업로드하지 않는다.

## 1차 MVP 제외 기능

아래 기능은 구현하지 말고 TODO 또는 2차 기능으로 남긴다.

- 알림 기능
- 퇴근 후 라이딩 추천 알림
- 라이딩 중 비구름 접근 알림
- 복귀 추천 알림
- HealthKit 연동
- GPX 내보내기
- 인스타그램 자동 업로드
- 블로그 자동 작성/게시
- 영상 자동 생성
- 코스 추천
- 월간/연간 리포트
- AI 라이딩 코치
- 커뮤니티 기능

## 완료 기준

1차 구현 완료 기준:

- 앱 실행 시 HomeView가 표시된다.
- Mock 날씨/미세먼지 데이터로 라이딩 점수가 계산된다.
- 라이딩 시작 버튼을 누르면 기록 화면으로 이동한다.
- 위치 권한을 요청할 수 있다.
- GPS 포인트를 받을 수 있는 구조가 있다.
- 라이딩 중 거리/시간/속도 값이 갱신되는 구조가 있다.
- 종료를 누르면 요약 화면으로 이동한다.
- 요약 화면에 거리/시간/평속/날씨/미세먼지 정보가 표시된다.
- 공유 카드 미리보기를 만들 수 있다.
- Supabase 저장 구조와 서비스 초안이 있다.
- 네트워크 실패 대비 로컬 임시 저장 구조가 있다.
- 알림, HealthKit, GPX, 자동 업로드는 TODO로 분리되어 있다.
