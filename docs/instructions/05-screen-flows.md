# 화면 흐름 지침

## 전체 흐름

```text
HomeView -> RideTrackingView -> RideSummaryView -> ShareCardView
```

## HomeView: 오늘탈까

역할:

- 오늘 자전거 타기 좋은지 판단한다.

포함 요소:

- 라이딩 점수 카드
- 한 줄 판단 메시지
- 날씨 요약 카드
- 미세먼지 요약 카드
- 바람/습도/강수 정보
- 라이딩 시작 버튼

예시 메시지:

- 오늘 18:00~20:30 라이딩 추천
- 짧게 30km 이하 추천
- 복귀길 맞바람 주의
- 비 가능성 있어 장거리 비추천
- 초미세먼지 나쁨, 실내 운동 추천

## RideTrackingView: 라이딩 중

역할:

- 라이딩 중 GPS 기록과 핵심 수치를 표시한다.

포함 요소:

- 지도
- 이동 경로
- 경과 시간
- 거리
- 현재 속도
- 평균 속도
- 일시정지 버튼
- 재개 버튼
- 종료 버튼

UI 원칙:

- 숫자는 크고 명확해야 한다.
- 지도와 핵심 수치 중심으로 구성한다.
- 라이딩 중 조작은 최소화한다.
- 버튼은 장갑을 끼고도 누를 수 있을 정도로 크게 만든다.

## RideSummaryView: 오늘탔다

역할:

- 종료된 라이딩 결과를 요약한다.

포함 요소:

- 총 거리
- 총 시간
- 이동 시간
- 평균 속도
- 최고 속도
- 경로 미니맵
- 시작 시점 날씨
- 종료 시점 날씨
- 미세먼지/초미세먼지 요약
- 사용자 메모
- 공유 카드 만들기 버튼

## ShareCardView

역할:

- 공유 카드 미리보기를 보여주고 이미지 저장/공유로 연결한다.

포함 요소:

- 날짜
- 앱 이름
- 거리
- 시간
- 평균 속도
- 경로 미니맵
- 날씨 요약
- 미세먼지 요약
- 메모
- 이미지 저장/공유 버튼

공유 원칙:

- 자동 업로드는 하지 않는다.
- iOS 공유 기능을 사용해 사용자가 직접 공유한다.
